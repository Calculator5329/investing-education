# Investing Education

An interactive educational game teaching stock market fundamentals through hands-on portfolio management.

## What It Is

Investing Education is a gamified learning platform where users manage a stock portfolio through different market scenarios and investment levels. Build positions, track performance against a benchmark, and learn investment principles through real-time feedback. The game features multiple levels of increasing difficulty, each with unique market conditions and learning objectives.

## Tech Stack

- React 19 with TypeScript
- Vite for fast development
- MobX for state management
- Mobx-React-Lite for reactive components

## Getting Started

```
npm install
npm run dev
```

Launch the game and select a level to begin. Manage your portfolio by buying and selling stocks to beat the benchmark and complete each level's objectives.
